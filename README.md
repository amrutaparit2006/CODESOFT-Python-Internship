# CODSOFT Python Programming Internship – Tasks 1, 2 & 3

## Task 1 – To-Do List
Features:
- Add task
- View tasks
- Update task
- Delete task
- Mark task as completed

File: `task1_todo_list.py`

## Task 2 – Calculator
Features:
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Division-by-zero handling

File: `task2_calculator.py`

## Task 3 – Password Generator
Features:
- User chooses password length
- Uses uppercase/lowercase letters, digits and symbols
- Uses Python `secrets` for random generation
- Minimum length validation

File: `task3_password_generator.py`

## How to Run
Install Python 3, then open the folder in VS Code.

Run:
```bash
python task1_todo_list.py
python task2_calculator.py
python task3_password_generator.py
```
